Cómo se calcula

Pythagorean usa RS y RA con exponente 1.83. El cruce usa Log5. La probabilidad de localía parte de 54%/46%. Las carreras proyectadas usan las tasas ofensivas y defensivas de local/visitante. El total se redondea a 0.5 y el ±1.5 usa una normal con SD 4.24. Los datos se obtienen de MLB Stats API y se recalculan según la fecha seleccionada.
